# Contributing

When I make a material change, I first map it to a requirement or acceptance criterion. Where practical, I add a failing test, implement the smallest compliant behavior, run regression validation, update the documentation and traceability, and then review the change as one coherent unit.

I do not fabricate approvals, execution evidence, metrics, or test results. The governing lifecycle and assessment expectations are documented in `docs/governance/constitution.md` and `specs/001-agentic-url-shortener/`.
