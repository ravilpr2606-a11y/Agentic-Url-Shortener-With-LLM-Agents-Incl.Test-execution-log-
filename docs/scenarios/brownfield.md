# Brownfield Scenario


I use this scenario to demonstrate impact analysis before changing existing behavior.
Input: add or modify a capability against the existing URL shortener.

Before implementation the orchestration records impacted components, interfaces, persistence, tests, telemetry, documentation, security/reliability risks and rollback/compensation implications. This makes the pre-existing URL shortener a deliberate brownfield baseline rather than a hidden shortcut.
